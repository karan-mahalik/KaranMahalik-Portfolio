## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/karan-mahalik/KaranMahalik-Portfolio.git
   cd KaranMahalik-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deployment to GitHub & Vercel

### Step 1: Push to GitHub
When you have created the empty repository on GitHub (`https://github.com/karan-mahalik/KaranMahalik-Portfolio`):

```bash
git remote add origin https://github.com/karan-mahalik/KaranMahalik-Portfolio.git
git push -u origin main
```

### Step 2: Deploy to Vercel
1. Open your Vercel dashboard: [vercel.com/karan-mahaliks-projects](https://vercel.com/karan-mahaliks-projects)
2. Click **"Add New Project"** and select **"Import Git Repository"**.
3. Select `karan-mahalik/KaranMahalik-Portfolio`.
4. Framework Preset: **Vite** (auto-detected).
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **"Deploy"**. The site will be live in seconds with automatic CI/CD!
